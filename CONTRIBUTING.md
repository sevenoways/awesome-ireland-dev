# Contributing

Thanks for helping! To add a resource:

1. It must be useful to developers building for Ireland (APIs, datasets, libraries, tools).
2. Add it to the right section, as `- [Name](link) - Short description ending with a full stop.`
3. Say whether an API needs a key or is paid.
4. One resource per pull request, please.

Broken or dead links can be reported as an issue or fixed in a PR.
